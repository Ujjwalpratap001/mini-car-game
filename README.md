# Velocity X — 3D Car Racing

A browser-based 3D racing mini-project built with HTML, CSS,
JavaScript, and Three.js.

## Features

- Three sports cars
- Third-person racing camera
- AI racing opponents
- Procedurally generated racing circuit
- Speedometer, lap counter, and race timer
- Keyboard and mobile touch controls
- Pause, restart, and race completion screens
- Responsive interface

## Controls

| Key | Action |
|---|---|
| W / Arrow Up | Accelerate |
| S / Arrow Down | Brake |
| A / Arrow Left | Steer left |
| D / Arrow Right | Steer right |
| Space | Brake |
| R | Reset player position |
| Escape | Pause / resume |

## Run Locally

Use Visual Studio Code with the Live Server extension.

1. Open the project folder in VS Code.
2. Right-click `index.html`.
3. Select Open with Live Server.
4. Open the provided local HTTP address in your browser.

An internet connection is required to load Three.js from its CDN.

## Deploy on GitHub Pages

1. Upload all project files to the repository root.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose `main` and `/(root)`.
5. Click Save.

Your website will be published at:

https://USERNAME.github.io/REPOSITORY-NAME/
